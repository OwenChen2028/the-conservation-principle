Description:
The game revolves around a size-manipulation mechanic. Using a special gun, the player can shrink objects to store mass, then transfer that mass into other scalable objects to make them larger and heavier. An object’s size affects how it interacts with the environment. Larger objects have more weight and inertia, while smaller objects are lighter and easier to move.
